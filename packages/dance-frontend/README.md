# dance-frontend —— 舞曲排曲台前端（Vite + React + Semi）

独立可部署的静态产物，**无 CDN 依赖**。构建产物由 `dance-backend` 托管（`webDir` 默认指向本目录 `dist`）。

## 开发

```bash
npm install
npm run dev        # http://localhost:5173 ，/api 与 /media 代理到 http://127.0.0.1:8790
```

## 构建 / 部署

```bash
npm run build      # 输出 dist/
```

- 生产：把 `dist/` 交给 `dance-backend`（默认已指向），或任意静态服务器 + 反向代理 `/api`、`/media` 到后端。
- 因为 `base: './'`，产物可放子路径。

## 功能
- **曲库**：按舞种浏览，或切到「**我喜欢**」合集（跨舞种、稳定保留，播放识别舞种后也不会移出）；支持深链 `/?liked=1`、`/?type=舞种`。曲目行显示 **舞种 / 曲风（欢快·舒缓）/ BPM**；节奏不稳的显示红色「**不适合舞曲**」提示；可**编辑**（歌名/歌手/舞种/是否适合）与**移除**；「**导入「我喜欢」**」一键把 QQ「我喜欢」导入（**只导元数据**，播放时再缓存 + 自动识别舞种）；「**缓存并分类**」把当前视图逐首下载 HQ 并自动识别舞种（后台任务，受缓存上限约束）。
- **搜索**：可在 **QQ音乐 / 网易云音乐** 间切换；结果右侧「+」一键加入曲库（选目标舞种）。
- **导入来源**：**QQ音乐歌单**（导入到曲库 / 解析预览 / 克隆到我的歌单）、**网易云**（歌单/单曲链接或 ID）、**本地/社团文件夹**（按 `舞种-歌名-歌手` 扫描入库，文件原位）、**自建服务器直链**（每行一个 URL）、**百度网盘**（分享链接+提取码，需在设置配 BDUSS Cookie）。
- 曲目行显示 **来源 chip**（网易云/本地/直链/网盘）；**按来源筛选**时出现「**缓存本来源**」「**清空本来源**」；设置里可填 `neteaseCookie`、`baiduCookie`。
- **排曲**：目标时长 + 各舞种权重 → 生成；**拖拽排序 / 一键乱序 / 按舞种归组 / 单曲时长裁剪（秒）**；保存与编辑已保存排曲；「播放全部」进 `/play`、「大屏播放」进 `/wall`。
- **舞会信息 + 导出**：填舞会名称/时间/地点/主办/备注；**导出长图**（html2canvas 海报 PNG）；**导出/导入传递文件**（`.hdbc-setlist.json`）。
- **按文件名校准**（设置里）：扫描本机按《HBDC 规则》命名（`舞种-歌名-歌手`）的目录，匹配曲库后直接改舞种，未匹配的可作为本地文件加入曲库。

## 界面设计

统一设计系统（`src/styles.css` 里的 CSS 变量）：象牙白 `#F5F3EE` / 香槟金 `#C5A059` / 墨蓝 `#1A3A5F`；**支持明/暗主题**（顶栏切换，`localStorage` 记忆）。
- 顶栏：品牌 + 分段式导航（Semi Tabs button）+ **明/暗切换** + 用户胶囊 + 设置。
- 内容为**卡片面板**（`.panel`），带柔和投影与圆角；曲目行含**封面缩略图**、舞种/曲风/缓存/BPM 标签、**图标操作**（播放/编辑/移除）。
- 精致的空状态、进度条、拖拽排曲行（金色序号徽章 + 抓取手柄）、导出海报离屏渲染。
- 播放页 `/play` 与大屏 `/wall` 共用同一套配色与字体；`/play` 有入场淡入。
- **登录**：QQ/微信二维码。
- **编辑**：曲库每行可改歌名/歌手/舞种，并手动标记是否适合当舞曲。
- **播放页**：基于开源 **APlayer**，展示封面、曲名、进度、完整播放列表、歌词；**独立全屏路由 `/play`**（控制台点「播放/播放全部」打开）。
- **设置**（右上角）：管理员口令 + **自定义音频缓存目录**（保存即生效）+ **HQ 音质（320k，下载后统一转 mp3）** + **缓存上限（默认 20GB，超限按最近播放 LRU 淘汰）** + **按文件名校准**。
- **大屏模式**（`/wall`）：舞会现场大屏用，基于 **howler.js**（音频）+ **anime.js**（动画），象牙白 / 香槟金；展示封面（模糊背景）、大字曲名、进度、歌词、接下来列表；**切歌自动淡出→切换→淡入**（音频 0.7s/0.9s）+ **封面/背景双图层交叉溶解** + **封面 Ken Burns 缓慢缩放** + **金色光晕脉冲**；空格播放/暂停、←→ 切歌、F 全屏。控制台「排曲」页点「大屏播放」打开。
